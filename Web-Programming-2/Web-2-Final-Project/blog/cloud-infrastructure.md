# Cloud Infrastructure

By definition *Cloud Infrasturcture* is
: the collection of hardware and softeware resources that make up the cloud. 

In practice cloud providers  are tasked with maintaining global data centers with IT infrastucture components; for example servers and networking equipment to name a few of the many responsibilities they can have.

For the purpose of this final project and for the class of IT Dev Ops we use, cloud infrastructure through a method known as virtual machines. We create small instances to experiment with the maintainance of the instance's features, which also include  "cloud infrastructure services."
